# Legacy Spike

The root-level `index.html`, `styles.css`, and `src/` directory are a disposable
shader/editor spike created before the approved Phase 1 architecture.

Production work now lives in the Vite+ monorepo:

- `apps/editor`
- `packages/*`

Do not extend the legacy spike for production features. Keep it only as a
temporary visual/rendering reference until the Vite+ app fully covers the initial
and selected-text states.
